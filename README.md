# Site de Estudos - Linguagem de Programação

Projeto estático em HTML, CSS e JavaScript para estudar para a prova de Linguagem de Programação.

## Como abrir

Abra o arquivo `index.html` no navegador.

## Arquivos

- `index.html` - estrutura das telas.
- `style.css` - layout responsivo e aparência.
- `questions.js` - banco de questões e revisão rápida.
- `script.js` - simulados, localStorage, histórico, erros e desempenho.

## Conteúdo cadastrado

- 30 questões principais baseadas no PDF da Aula 6.
- 15 questões extras baseadas nas Aulas 1 a 5 e material extra.
- Revisão rápida dos principais assuntos de POO.
- Priorização das questões da Aula 6 nos simulados.
- Registro de acertos, erros, histórico e desempenho por assunto com localStorage.
